# 云枢智学 需求文档

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 产品定位 | AI 赋能的智能面试训练平台 |
| 核心闭环 | 学科 → 阶段 → 题目 / 课程 / 路线；刷题 → 错题 → AI 面试 → 报告 → 补强 |
| 学员端 | portal，独立部署，导航：首页 / 学习路线 / 题库 / AI面试 |
| 管理端 | admin，独立部署，菜单：概览 / 内容管理 / 学员管理 / 系统管理 |

### 1.1 内容体系

```
学科（8 个）
 ├── 阶段（一对多）
 │    └── 题目（挂载在阶段下）
 ├── B站课程（一对多，课程库独立维护，可被多条路线引用）
 └── 学习路线（引用课程，课程顺序即学习顺序）
```

### 1.2 角色

| 角色 | 所属端 | 权限范围 |
|---|---|---|
| 游客 | 学员端 | 浏览首页、注册、登录、找回密码 |
| 学员 | 学员端 | 刷题练习、错题本、学习路线、AI 模拟面试、个人中心 |
| 超级管理员 | 管理端 | 全部权限（含系统管理） |
| 内容审核 | 管理端 | 查看全部内容 + 题库审核；无新增 / 编辑 / 删除 / 导入导出权限 |
| 运营人员 | 管理端 | 除系统管理、用户管理外的全部操作；不含题库审核权限 |

## 3. 学员端功能需求

### 3.1 首页

**导航栏**：云枢智学（回首页）｜首页｜学习路线｜题库｜AI面试｜用户下拉（个人中心 / 我的错题 / 面试记录 / 管理后台 / 退出登录），其中「管理后台」仅后台账号登录学员端时显示，普通学员不可见

| 区块 | 功能点 |
|---|---|
| Hero 首屏 | 主标题、副标题；按钮「海量题库」→ 题库中心，「开始AI面试」→ AI 面试；展示 4 项平台数据（精选面试题、注册学员、AI面试次数、好评率），数字带递增动画 |
| 快速开始 | 4 张入口卡：随机练习10题 → 练习页随机模式；开始AI面试 → 面试配置页；继续上次学习 → 练习页续做；规划学习路线 → 学习路线页 |
| 核心功能 | 4 张功能卡：海量题库、AI模拟面试、刷题练习、学习路线，各跳对应页面 |
| 学习统计 | 连续学习天数、正确率、总练习数；「查看全部」→ 个人中心 |
| 近 7 天练习 | 柱状图按日展示练习量，今日高亮；右侧显示「今日已刷 N 题」 |
| 热门阶段 | 按学科下的阶段渲染卡片（阶段名 + N 道题目），点击进入题库中心对应阶段 |
| AI 面试介绍 | 卖点 4 条（智能出题 / 实时评分 / 面试报告 / 海量知识）+ 演示对话 + 「立即体验」 |
| 页脚 | 三列链接：产品（学习路线 / 题库 / AI面试）、支持（帮助中心 / 意见反馈 / 联系我们）、关于（关于我们 / 用户协议 / 隐私政策），其中支持/关于两组外链本期为占位、不开发对应页面；版权行；「管理后台」入口（对所有访客常驻，点击进入管理端登录页，两端账号体系独立、需单独登录） |
| 新手引导 | 首次进入弹出三步引导（选择技术方向 → 开始刷题练习 → AI面试检验）；「开始学习」与「跳过引导」均记录后不再展示 |

### 3.2 注册 / 登录 / 找回密码

#### 登录

| 项 | 内容 |
|---|---|
| 登录方式 | Tab 切换：账号密码登录（默认）、手机验证码登录 |
| 账号密码 | 手机号/邮箱、密码；「记住我」（默认勾选）；「忘记密码？」→ 找回密码页 |
| 验证码 | 手机号、验证码；「获取验证码」点击后 60 秒倒计时，倒计时内禁用 |
| 其他 | 第三方登录入口：微信 / QQ / GitHub；「立即注册」→ 注册页 |

#### 注册

| 项 | 内容 |
|---|---|
| 字段 | 手机号、验证码（含获取验证码 60 秒倒计时）、设置密码（6-20 位）、确认密码 |
| 密码强度 | 三档强度条（弱 / 中 / 强），按长度 ≥6、含大小写字母、含数字与特殊字符逐项加分 |
| 协议 | 勾选「我已阅读并同意《用户协议》和《隐私政策》」，未勾选拦截注册 |
| 流程说明 | 左侧步骤条为引导展示（创建账号 → 完善信息 → 开始训练，仅第 1 步激活）；注册为单页表单，不设独立步骤页；注册成功后引导至个人中心完善资料 / 选择技术方向 |

#### 找回密码

| 步骤 | 内容与校验 |
|---|---|
| 1 验证手机 | 手机号（11 位校验）、验证码（6 位校验）、获取验证码；「返回登录」 |
| 2 重置密码 | 新密码（≥6 位）、确认密码（两次一致校验） |
| 3 完成 | 提示重置成功，「立即登录」→ 登录页 |

#### 安全与频控

> ✅ 已确认纳入本期（架构设计阶段 T6 确认，阈值采纳建议值并定稿）。本节为原需求文档未定义、经确认后补充的能力，覆盖登录、注册、找回密码三类账号操作。阈值统一在服务端实现，前端仅做与之匹配的交互提示（如 60 秒倒计时）；具体阈值不在前端暴露。

| 项 | 内容 |
|---|---|
| 登录失败锁定 | 同一账号连续 5 次密码错误后锁定 5 分钟，锁定期间登录失败并提示「账号已锁定，请 X 分钟后重试」；登录成功后失败计数清零 |
| 验证码获取频控 | 同一手机号 60 秒内仅可获取 1 次（与前端 60 秒倒计时一致）；同一手机号每日最多 10 次，超出提示「今日获取次数已达上限」 |
| 验证码校验限制 | 同一验证码连续校验失败 5 次后立即失效，需重新获取 |
| 接口请求频控 | 登录、注册、找回密码、验证码、AI 面试发起等接口按 IP + 账号双维度限制请求频次，超限返回业务错误码并提示「操作过于频繁，请稍后再试」，不暴露具体阈值 |

| 区域 | 功能点 |

| 题目卡 | 第 N 题、题干；题型与难度徽章；阶段名、N 人做过、正确率、标签；「查看解析」「开始练习」 |

### 3.5 刷题练习

进入页面即弹出练习模式选择弹窗，选定模式后进入答题视图。

#### 练习模式

| 模式 | 说明 |
|---|---|
| 顺序练习 | 按题库顺序逐题作答 |
| 随机练习 | 打乱题目顺序作答 |
| 取消 | 右上 ✕ 或 Esc 关闭弹窗，视为放弃本次练习，返回题库中心 |

#### 界面

| 区域 | 功能点 |
|---|---|
| 左侧面板 | 返回题库；练习标题（取所选阶段名）；进度条 + 「当前题 / 总题数」；计时器（时:分:秒，记录本次练习用时）；答题卡（题号网格，点击跳题）；「结束练习」 |
| 答题区 | 题型标签 + 题干；选择题按 A/B/C/D… 渲染选项；简答题文本域 + 「提交答案」 |
| 简答批改 | 提交后展示 AI 评分中动画，随后输出评分卡：分数（x/10）、评语、关键点、参考答案 |
| 答案解析 | 「答案解析」卡：结果徽章（回答正确 / 回答错误 / 未作答）+ 正确答案 + 解析 |
| 底部操作 | 上一题（首题禁用）、查看解析、下一题（末题文案为「完成」，点击等同结束练习） |
| 快捷键 | `←` 上一题、`→` 下一题、`Enter` 提交答案 / 下一题、`?` 显示快捷键面板 |

#### 答题卡状态

| 颜色 | 含义 |
|---|---|
| 白底灰边 | 未作答 |
| 蓝底 | 当前题 |
| 绿底 | 已答 / 判定正确（含简答通过） |
| 红底 | 判定错误 |

#### 规则

- 单选互斥，多选可多选；已批改题目不可修改。
- 简答题得分 ≥6 分记为通过；未提交的简答不可查看解析、不可进入下一题。
- 「结束练习」：存在未作答简答题时提示并自动跳到该题；否则弹出二次确认（含「还有 N 道题未完成」分支），确认后停止计时、清除会话并返回题库。
- 练习进度本地持久化（题序、当前题号、答案、批改状态、AI 评分、已用时长）；再次进入时提示「检测到未完成的练习，是否继续？」，可选「继续」（恢复进度）或「重新开始」（清空并重选模式）。
- 切换题目时，已批改的选择题自动展开解析，已提交的简答题回显评分结果。

### 3.6 错题本

| 模式 | 功能点 |
|---|---|
| 统计卡 | 顶部四张统计卡：错题总数 / 待复习 / 已掌握 / 掌握率 |
| 高频错题 Top3 | 顶部展示错误次数最多的前 3 道待复习错题（按错误次数降序），可点入重做 |
| 浏览模式 | 错题卡片：错误次数徽章（高频易错 / 多次错误 / 偶尔错误）、纠正进度「已纠正 N/3 次」、题干、所属分类、最近答错日期、错误次数、你的答案、正确答案；操作：重新做题 / 标记已掌握 / 移除错题 |
| 批量操作 | 勾选后底部滑出操作栏「已选择 N 项」+ 批量标记已掌握 / 批量移除 / 取消选择，均二次确认 |
| 重做模式 | 按待复习错题顺序逐题练习；提交后标出正确与错选并展示解析；每题答对一次「已纠正次数」+1，累计 3 次自动标记为已掌握；支持上一题 / 下一题 / 退出练习 |

**规则**

- 错误等级：错误次数 ≥3 为高频易错，=2 为多次错误，否则偶尔错误。
- 已掌握错题置灰，不再显示「标记已掌握」按钮。
- 无选项的题目提示「此题暂无可选的答题选项，请自行复习」并展示正确答案。
- 筛选与排序：状态（全部 / 待复习 / 已掌握）、分类、时间（全部 / 近 7 天 / 近 30 天）；排序按最近答错时间倒序或按错误次数倒序。
- 空态：浏览无结果显示「暂无错题」；重做无待复习题显示「没有待复习的错题」+「返回浏览」。

### 3.7 学习路线

| 区域 | 功能点 |
|---|---|
| 选择学科 | 全部学科卡片（图标、名称、M 条路线），一排 5 个、单选切换；卡片**不展示学习进度**（进度在下方路线详情区展示）；无启用路线的学科卡片弱化展示 |
| 路线切换 | 同一学科有多条启用路线时以 Tab 切换，Tab 上显示各路线进度 N/M；默认选中「最近学习」的路线 |
| 路线头部 | 路线名、适合人群、路线描述；统计：共 N 门课程、总计时长、按列表顺序学习；进度 N/M 与百分比进度条 |
| 路线课程 | 有序课程列表：序号、封面、课程标题、BV号、时长、「去B站学习」（新标签打开 B 站视频页）、「标记已学完」 |
| 标记已学完 | 学完一门课后可标记；标记后按钮置灰为「✓ 已学完」，仅可标记、不可取消；标记后路线 Tab、路线头部两处进度同步刷新 |

**空态**：未选学科「请选择一个学科方向」；学科无路线「该学科暂无学习路线」；课程为空「课程筹备中，敬请期待」。

> **补充说明（2026-11-04 学员端开发阶段确认，D4-24）**：本节原为「8 个学科卡片（图标、名称、**N 门课程**）」，实际开发时按用户确认调整为：① 学科卡片**动态取全部学科**（`subject` 表未删除记录，当前 9 个，含「其他学科」等未配置路线的学科），卡片数字由课程数改为**学习路线数量**；② 支持**一个学科多条学习路线**（页面流程 = 学科 → 路线 → 课程，路线 Tab 切换）；③ 新增**学习进度**展示（路线 Tab、路线头部两处）；④ 新增「**标记已学完**」（只标记、不取消）。**后续调整（同日二次确认）**：学科卡片仅展示「M 条路线」，**不再展示进度条与完成数**，卡片排布为**一排 5 个（9 个学科两排）**，进度只在路线 Tab 与路线头部展示。接口契约见 `docs/design/04.API接口设计.md` §4.6 与 D4-24。

### 3.8 AI 模拟面试

#### 3.8.1 面试配置

| 项 | 内容 |
|---|---|
| 技术方向 | 单选 8 项：AI应用与智能体开发（默认）、AI大模型开发、AI具身智能机器人开发、AI嵌入式_机器人开发、AI测试、AI运维、AI视觉设计、AI视频与短剧创作 |
| 面试难度 | 单选 3 项：简单（基础面试）、中等（进阶面试，默认）、困难（高级面试），各附适用人群说明 |
| 面试题目数量 | 下拉：3题 / 5题 / 8题 / 10题（默认）/ 15题 |
| 回答超时时间 | 固定 5 分钟，不可修改 |
| 配额 | 展示今日剩余 AI 面试次数；每日限额 5 次，用尽当日不可再发起、次日 0 点重置 |
| 开始 | 「开始AI面试」→ 携带方向、难度、题数、超时写入配置并进入面试页 |

#### 3.8.2 面试进行中

| 区域 | 功能点 |
|---|---|
| 顶部 | 退出面试；标题 + 当前方向与难度；网络状态（在线 / 离线）；计时器；题目进度「题目 x/N」；语音播报开关；「结束面试」 |
| 进度面板 | 答题进度 N/N、进度条、平均分、已用时间、难度标签 |
| 对话区 | AI / 用户消息气泡（含时间）；AI 消息支持重播朗读；分析中提示「AI面试官正在分析你的回答...」；思考中打字指示器；输入区（多行文本、语音输入按钮、发送按钮） |
| 侧边栏 | 「面试题目」列表（序号、题目简称、得分，当前题高亮，点击定位）；「面试统计」（已回答、总题数、平均分、用时）；面板可折叠 |

**规则**

- 作答方式：文本文作答（Enter 发送，Shift+Enter 换行，空内容不发送）；语音作答（浏览器语音识别，识别结果写入输入框；不支持时降级为模拟识别并提示）。
- 语音播报：默认开启，AI 消息自动朗读，支持全局开关与单条重播。
- 每题提交后依次展示分析中 → 评分中提示 → 思考中 → 下一题；每题给出 0-10 分评分，配色分级（≥8 绿、≥6 橙、<6 红），侧边栏同步显示得分。
- 全部题目答完后 AI 给出结束语，弹出「是否查看面试报告？」确认，确认后进入报告页。
- 「结束面试」二次确认后保存进度并生成报告。
- 会话持久化：答题进度、消息、当前题号、已回答数、用时、得分列表本地保存，未完成会话再次进入时提示「是否继续上次的面试？」（明细：已完成 X/N 题 · 用时），可选「继续」或「重新开始」。

| 区块 | 功能点 |

| 行操作 | 编辑、删除 |
| 新增 / 编辑表单 | 课程名称（必填）、BV号（选填，全库唯一）、封面图片 URL、时长（必填，格式 小时:分钟）、所属学科（必填，下拉多选：8 个学科 + 「其他学科」兜底项）、来源（B站 / 其他）、课程链接 |
| 批量导入 | 上传 Excel 文件（.xlsx / .xls）→ 解析校验（任一无效行即整份拒绝，报出行号与原因）→ 预览（新增 / 覆盖更新 / 警告）→ 确认导入；弹窗内提供「下载导入模板」 |
| 空态 | 「暂无匹配的课程，试试调整筛选条件」 |

> 所属学科下拉支持多选：可同时关联多个学科，**按选择顺序第一个作为主学科，其余作为关联学科**；含「其他学科」兜底项，用于不属于任何已有学科的课程，该选项需单独选择（不可与其他学科同时选中）；填写说明中同步列出该选项。

> **导入文件格式**：表头行按**列名识别**（列顺序可变），必需列「课程名称」「时长（分钟）」缺一即整份文件报错；可选列「所属学科」「来源」「BV号」「封面」「播放链接」。一张工作表即可，单次 ≤ 2000 行、文件 ≤ 5MB。「所属学科」一格内可写多个学科（中英文逗号分隔），**第一个作为主学科，其余作为关联学科**。

> **导入语义（Excel 为权威数据源）**：BV号与库中已有课程重复时**覆盖更新**该课程；无 BV号时按「课程名称 + 来源」匹配。Excel 中为空的可选列**按空值写入**（所属学科为空 → 归入「其他学科」），不保留库中原值。关联学科**整体替换**。被学习路线引用的课程允许覆盖，预览页提示「其中 N 门课程已被 M 条学习路线引用」。列名不认识的学科视为**警告行**并归入「其他学科」。
> **校验口径**：任一行无效（课程名称缺失、时长非数字等）即**整份拒绝导入**，报出行号与原因明细，**一行数据都不写入**，修正后重新上传；与题库管理导入口径保持一致。单次上限 2000 行，超出提示分批导入。
> 权限口径：导入仅校验「新增」权限，覆盖更新已有课程不额外要求「编辑」权限。
>
> **列表顺序（阶段 8 确认）**：批量导入后列表展示顺序与 Excel 一致（Excel 第 1 行 → 列表第 1 个，覆盖更新的既有课程也按 Excel 行序重排）；多次导入按批次先后排列；非导入批次课程（种子 / 手动新增）排在其后，彼此保持最新在前。

## 6. 通用交互约定

| 项 | 约定 |
|---|---|
| 列表页 | 筛选条件（关键词 + 下拉）+ 表格 + 分页；筛选变更后页码重置为第 1 页 |
| 批量操作 | 勾选后出现批量操作条，支持跨页保留勾选；全选仅作用于当前页；未勾选时点击批量按钮给出提示 |
| 二次确认 | 删除、批量删除、清空日志、启禁用、重置密码、审核、上下架、结束练习 / 面试等破坏性或不可逆操作 |
| 删除语义 | 均为逻辑删除（软删除），删除后数据保留可恢复 |
| 提示反馈 | 统一 Toast，分成功 / 警告 / 错误三级；表单校验失败给出明确文案 |
| 权限控制 | 管理端按权限点控制菜单与操作按钮的可见性；无权限的操作入口不展示 |
| 空态 | 所有列表 / 卡片列表均需提供空态文案与引导操作 |
| 登录态 | 学员端与后台各自独立；未登录访问受限页面跳转对应登录页 |
