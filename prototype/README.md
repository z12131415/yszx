# 云枢智学 - 页面原型

## 数据模型架构

```
┌──────────────────────────────────────────────────────────┐
│                    学科 (Subject)                         │
│  AI应用与智能体 │ AI大模型 │ AI具身智能机器人 │ AI嵌入式_机器人 │ ... │
│  共8个AI学科，每个学科有独立的图标、描述、课程数量            │
│                                                          │
│  每个学科下可挂载多个 阶段 (Catalog)：                      │
│  AI应用与智能体开发 → [AI应用基础, Spring生态, 数据库, Redis, 微服务] │
│  AI大模型开发 → [Python基础]                                │
│  AI视觉设计 → [AI视觉基础]                                 │
│  其他学科 → 暂无阶段（可后续添加）                            │
└───────┬──────────────────┬───────────────────────────────┘
        │ 一对多            │ 一对多
        ▼                   ▼
┌───────────────┐  ┌──────────────────────┐
│  题库 (Question)│  │   学习路线 (Route)      │
│  挂载在阶段下   │  │   引用 courseIds 数组    │
│  catalogId关联  │  │   课程1 → 课程2 → ...   │
└───────────────┘  └──────────┬───────────┘
                              │ 多对多
                   ┌──────────┴───────────┐
                   │  B站课程库 (Course)      │
                   │  BV号唯一标识，36门课程    │
                   │  可被多条路线引用          │
                   └──────────────────────┘
```

## 项目结构

```
prototype/
├── css/                # 公共资源，学员前台与管理后台共用
│   ├── common.css      # 公共样式（变量、按钮、表单、组件）
│   ├── layout.css      # 学员前台布局样式（导航栏、侧边栏、工具栏）
│   └── admin.css       # 管理后台样式
├── js/
│   └── common.js       # 公共JavaScript（工具函数、模拟数据）
├── assets/             # 静态资源
├── portal/             # 学员前台（C端）
│   ├── index.html      # 首页
│   ├── login.html      # 登录页
│   ├── register.html   # 注册页
│   ├── forgot-password.html # 找回密码页
│   ├── profile.html    # 个人中心页
│   ├── questions.html  # 题库列表页
│   ├── practice.html   # 刷题练习页
│   ├── wrong-book.html # 错题本页
│   ├── routes.html     # 学习路线页
│   ├── ai-config.html  # AI面试配置页
│   ├── ai-interview.html    # AI模拟面试页
│   ├── interview-report.html  # 面试报告页
│   └── interview-history.html # 面试历史页
└── admin/              # 管理后台
    ├── login.html      # 后台登录页
    ├── index.html      # 数据看板
    ├── subjects.html   # 学科管理（含阶段）
    ├── courses.html    # B站课程库
    ├── questions.html  # 题库管理
    ├── question-bank.html  # 面试题库管理
    ├── routes.html     # 学习路线管理
    ├── students.html   # 学员管理
    ├── users.html      # 用户管理
    ├── roles.html      # 角色管理
    ├── logs.html       # 操作日志
    └── settings.html   # 系统设置
```

> 两个端的页面均以 `../css/`、`../js/` 引用顶层公共资源；跨端跳转用 `../admin/xxx.html`、`../portal/xxx.html`。

## 已实现功能

### 前台页面（13个）
- ✅ 响应式布局，支持移动端
- ✅ 导航栏用户下拉菜单（根据角色显示管理后台入口）
- ✅ 登录/注册页Tab切换
- ✅ 找回密码三步式流程
- ✅ 个人中心信息管理

#### 首页增强
- ✅ **快速开始**：一键随机练习、开始AI面试、继续上次学习
- ✅ **学习统计**：7天连续学习展示、每日练习量柱状图
- ✅ **新手引导**：首次使用三步引导蒙层（localStorage记录）
- ✅ **计数动画**：统计数据数字递增动画效果

#### 题库 & 刷题
- ✅ 题库阶段筛选、难度筛选、类型筛选
- ✅ 题目"查看解析"和"开始练习"两种入口
- ✅ **两种练习模式**：顺序练习、随机练习（Fisher-Yates洗牌）
- ✅ **简答题AI批改**：textarea输入、AI评分动画、评分展示、关键点提示、参考答案
- ✅ **继续上次练习**：sessionStorage持久化，断点续练
- ✅ **键盘快捷键**：← → 切换题目，Enter提交，? 查看快捷键面板

#### 错题本
- ✅ 错题筛选（阶段、时间、状态、排序）
- ✅ 标记已掌握、移除错题
- ✅ **错题重做模式**：逐题练习、提交批改、连续正确3次自动标记掌握
- ✅ **批量操作**：复选框选择、批量标记掌握/移除
- ✅ **高频错题Top3**：按错误次数排序展示

#### AI面试
- ✅ AI面试配置页（方向、难度、题目数量、超时时间）
- ✅ AI面试对话式交互、实时评分
- ✅ **中断恢复**：localStorage持久化，检测未完成面试提供继续/重选
- ✅ **进度面板**：已回答数量、平均分、进度条、计时器
- ✅ **面试摘要侧边栏**：题目列表+评分、面试统计
- ✅ **语音输入模拟**：点击录音→模拟语音识别→填入textarea
- ✅ 网络状态检测（在线/离线指示器）

#### 面试报告 & 学习路线
- ✅ **待提升项**：每条 = 问题描述 + 一句指导性建议文案（不给具体阶段，也不做跨页跳转）
- ✅ **改进建议**：编号建议列表
- ✅ **能力提升建议**：推荐题目 / 推荐课程 / 推荐再次面试 3 张卡，纯文案说明，不带跳转按钮
- ✅ **分数趋势对比**：与上次同方向面试对比（↑提升/↓下降）
- ✅ **学科卡片**：动态列出全部学科（一排 5 个），卡片**只显示「M 条路线」**，不显示进度（进度只在路线 Tab 与路线头部展示）
- ✅ **路线切换**：一个学科有多条启用路线时显示路线 Tab（含各路线进度 N/M），默认选中「最近学习」的路线
- ✅ **路线进度**：路线头部展示 总课程数 / 总时长 / 已完成 N/M + 进度百分比与进度条
- ✅ **标记已学完**：课程行「标记已学完」按钮 → 置灰「✓ 已学完」，仅可标记不可取消，标记后卡片/Tab/头部进度实时联动
- ✅ **空状态**：未选学科、该学科暂无学习路线、路线暂无课程 三种提示

- ✅ 饼图（题目学科分布）
- ✅ 最近活动列表

- ✅ **题目详情**：格式化展示题目、选项、标签、统计
- ✅ **批量操作**：批量上架、下架、删除

#### 面试题库管理
- ✅ **题目列表**：跨学科总览，列为「题目 / 学科 / 来源 / 难度 / 主题 / 操作」，题干关键字 + 学科 + 主题 + 难度筛选，分页（10/20/50 条每页）
- ✅ **列职责**：学科单独成列（与筛选下拉同一维度）；来源列只讲这份题的出处（文档名 + 第 N 题），手工录入的标「✍️ 手工录入 / 无来源文档」
- ✅ **两个来路**：手动导入 Excel 入库（主，不带标记）、手工录入（绿标），列表与详情都标来源
- ✅ **只看未分类**：单独勾选框，与主题筛选互斥，用于复查还没标主题的题
- ✅ **主题筛选**：自由输入文本框，按题干主题文本**模糊匹配**（对应 A-I01 的 `topic` 入参）；不再有词表下拉与「· 词表外」标注 —— 主题词表与主题维护本轮搁置
- ✅ **题目详情**：主题/难度/标签、题干、参考答案、来源（学科 / 文档名 第 N 题 + 源 Excel 行号）
- ✅ **录入题目**：选学科 + 填题干/参考答案/主题/难度/标签，新题标记为「手工录入」，无来源文档；主题为**自由输入**（不给词表候选，≤50 字，留空=未分类）
- ✅ **导入 Excel**：传 .xlsx / .xls 题库文件（6 列：所属学科 / 题干 / 难度 / 主题 / 标签 / 参考答案，按表头名识别、列顺序可变），两段式 —— 先解析预览（文件信息 + 涉及学科汇总 + 告警 + 逐行结果），再确认入库；弹窗内不选学科，以文件「所属学科」列为准，一个文件可含多个学科；确认时逐行取文件中的主题/难度/标签，不再统一覆盖；文件不入库，来源只留文档名与数据行序号；弹窗内提供「下载导入模板」
- ✅ **编辑题目**：与录入同构的全字段编辑（学科/题干/参考答案/主题/难度/标签），必填与校验口径同录入（学科、题干必填，主题自由输入且 ≤50 字、留空=未分类）；来源列只讲出处，编辑不改变来源记录（Excel 来的题仍标原文件与行号，手工录入的仍标「✍️ 手工录入」，不标已修改）
- ✅ **删除题目**：逻辑删除确认，提示按来路区分（手动导入的 Excel 系统不留存，删了只能重新导入）
- ✅ **两种空态**：只看未分类时提示「都标好主题了」，其余情况提示「没有符合条件的题目」

## 使用方式

1. 直接在浏览器中打开 `portal/index.html` 即可预览学员前台
2. 访问 `admin/login.html` 进入管理后台登录页（直接看数据看板可开 `admin/index.html`）
3. 所有页面均使用本地CSS和JS，无需服务器；公共资源在同级 `css/`、`js/`，请保持目录结构完整

## 测试说明

- 在 `js/common.js` 中修改 `userInfo.role` 可切换用户角色：
  - `'admin'` - 管理员，可看到管理后台入口
  - `'student'` - 普通学员，隐藏管理后台入口

## 技术说明

- 纯HTML + CSS + JavaScript实现
- 使用CSS变量统一管理主题色
- 模拟数据存储在 `common.js` 的 `MockData` 对象中
- 交互效果通过原生JS实现
